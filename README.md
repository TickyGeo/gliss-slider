I used HTML, CSS and JS for this project.
You can slide the photos with 2 buttons (left and right) and with radio buttons in the bottom of the page. The main fitch is that the slides not just change. They gliss. There are a special div which has a special size which is more than the screen's width. And there are photos in a row, which are hidden and you can see them only after changing the slide.
